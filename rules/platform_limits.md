# Platform Limits & Constraints

This document defines the strict, non-negotiable character boundaries for all generated social content.

## 1. X (Twitter) - Free Tier
- **Hard Maximum**: 280 characters.
- **Safety Ceiling**: Aim for 240-270 characters to avoid rendering discrepancies.
- **Rule**: If character length > 280, the post is automatically invalid. Cut redundant words, emojis, or adverbs. Never truncate with an ellipsis `...`; reconstruct the sentence cleanly.

## 2. Threads (Meta)
- **Hard Maximum**: 500 characters.
- **Tone**: Relaxed, witty, conversational, micro-essay style.
- **Rule**: Length must be <= 500 characters.

## 3. LinkedIn
- **Hard Maximum**: 3,000 characters.
- **Optimal Range**: 1,200 – 2,400 characters.
- **The "See More" Rule**: First 140-210 characters must compel the reader to click "...see more".
- **Rule**: Length must be <= 3,000 characters.

## 4. Carousel (Multi-Slide Deck)
- **Slide Count**: 5 to 8 slides.
- **Per-Slide Limit**: <= 220 characters per slide.
- **Rule**: Keep text ultra-scannable. High visual-to-text ratio. Every slide must contain a `Visual Note` for design.

## 5. Substack (Newsletter / Deep-Dive)
- **Focus**: Depth, original research, nuanced perspective.
- **Components**:
  1. High-Open Rate Subject Line
  2. Subtitle / Preview Text (< 100 characters)
  3. Hook & Opening Narrative
  4. Core Arguments & Evidence
  5. Actionable Takeaway
  6. Reader Prompt / Engagement Question
